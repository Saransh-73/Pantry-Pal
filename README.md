# PantryPal

PantryPal is a recipe finder that matches recipes to ingredients in your pantry. It runs as a client-side React app and does not require an API key.

## Run locally

**Prerequisites:** Node.js 20.19+ or 22.12+, and npm.

1. Install dependencies:
   ```sh
   npm install
   ```
2. Start the development server:
   ```sh
   npm run dev
   ```
3. Open the local URL printed by Vite (by default, `http://localhost:3000`).

To verify a production build, run:

```sh
npm run lint
npm run build
```
